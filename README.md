# 網頁筆記

讀新聞、期刊、部落格時,直接在網頁上畫重點、寫筆記,之後集中回來複習。

- 選取文字,就能螢光標記、寫註解、加標籤
- 每篇文章可以另外寫「整頁筆記」
- 重新打開同一個網頁,標記會自動回來
- 🎙 **即時錄音轉錄**:對著麥克風說話,文字即時出現;英文可同步翻成繁體中文
- ✨ **AI 重點整理**:一鍵把逐字稿整理成摘要、重點、關鍵數字與待查證事項
- 「複習頁」集中列出所有標記與錄音,可搜尋、篩選、匯出
- 資料存在你自己的瀏覽器,不需要註冊帳號;錄音與 AI 功能為選用(詳見隱私說明)

## 安裝(Chrome)

也適用於 Edge、Brave、Arc 等以 Chromium 為基礎的瀏覽器。

1. 按本頁綠色的 **Code** 按鈕 → **Download ZIP**,下載後解壓縮。
2. 在 Chrome 網址列輸入 `chrome://extensions`。
3. 開啟右上角的 **開發人員模式**。
4. 按 **載入未封裝項目**,選擇解壓縮後裡面的 `extension` 資料夾。
5. 點工具列的拼圖圖示,把「網頁筆記」釘選起來,之後就能快速開啟。

提醒:請不要刪除或移動該資料夾,否則擴充功能會失效。Chrome 重新啟動時,有時會跳出「停用開發人員模式擴充功能」的提示,選擇保留即可。

## 使用方式

1. **標記**:在網頁上選取文字,按出現的「🖍 標記」,立刻畫上螢光,不用多一個步驟。想寫想法,改按「💬 註解」,輸入註解、標籤、選顏色後按儲存,儲存時也會一併畫記。
2. **修改**:點已標記的文字,可以編輯註解、換顏色或刪除。
3. **整頁筆記**:點網頁右下角的 ✎ 圓形按鈕,開啟側邊欄,寫下整篇文章的心得。
4. **複習**:點工具列的「網頁筆記」圖示 → 「開啟複習頁」。可以搜尋、點標籤篩選、排序、直接修改註解,並回到原文。
5. **備份**:複習頁可匯出 Markdown(貼到 Notion、Obsidian 等),也能備份或匯入 JSON。

## 錄音轉錄、翻譯與 AI 整理

1. 點工具列「網頁筆記」圖示 → **🎙 錄音轉錄 / 翻譯**,會開啟一個小視窗(可擺在影片旁邊)。
2. 按「開始錄音」,第一次使用請允許麥克風。選好語言,說話內容會即時變成文字。
3. 要翻譯與 AI 整理:按右上 ⚙,貼上你自己的 [Anthropic API key](https://console.anthropic.com/)。英文內容會即時翻成繁體中文;按「✨ AI 重點整理」會產生摘要與重點。
4. 錄音會自動儲存,可在複習頁的「錄音」查看、搜尋、匯出。

注意:
- 語音辨識使用 Chrome 內建引擎,只收麥克風的聲音,所以播放內容時需要讓麥克風收得到喇叭聲;音訊會送到 Google 處理。
- API 用量與費用由你自己的 Anthropic 帳號負擔。
- 辨識結果可能有錯字,尤其是專有名詞,AI 整理會標註不確定處。

## 注意事項

- 筆記只存在這一個瀏覽器。換電腦或重裝瀏覽器前,請先在複習頁「備份 JSON」。
- 清除瀏覽器資料或移除擴充功能,筆記可能一併消失,請定期備份。
- 如果網站改版,或內容是動態載入,舊的標記有時會找不到原文而不顯示;複習頁仍保留完整紀錄。
