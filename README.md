# 網頁筆記

讀新聞、期刊、部落格時,直接在網頁上畫重點、寫筆記,之後集中回來複習。

- 選取文字,就能螢光標記、寫註解、加標籤
- 每篇文章可以另外寫「整頁筆記」
- 重新打開同一個網頁,標記會自動回來
- 📄 **PDF 文獻也能做筆記**:匯入論文或文獻 PDF,直接選字標記、寫註解,筆記和網頁筆記放在同一個複習頁,一覽所有讀過的東西
- 📤 **分享**:把做好的筆記整理成一個分享頁(單一 HTML 檔),或複製一條連結,對方裝了這個擴充功能後,用連結開啟原文就能匯入你的標記與筆記
- 「複習頁」集中列出所有筆記,可搜尋、按標籤篩選、匯出
- 資料只存在你自己的瀏覽器,不需要註冊帳號,也不會上傳到任何地方

## 安裝(Chrome)

也適用於 Edge、Brave、Arc 等以 Chromium 為基礎的瀏覽器。

1. 按本頁綠色的 **Code** 按鈕 → **Download ZIP**,下載後解壓縮。
2. 在 Chrome 網址列輸入 `chrome://extensions`。
3. 開啟右上角的 **開發人員模式**。
4. 按 **載入未封裝項目**,選擇解壓縮後裡面的 `extension` 資料夾。
5. 點工具列的拼圖圖示,把「網頁筆記」釘選起來,之後就能快速開啟。

提醒:請不要刪除或移動該資料夾,否則擴充功能會失效。Chrome 重新啟動時,有時會跳出「停用開發人員模式擴充功能」的提示,選擇保留即可。

## 使用方式

1. **標記**:在網頁上選取文字,按出現的「🖍 標記」,立刻畫上螢光,不用多一個步驟。想寫想法,改按「💬 註解」,輸入註解、標籤、選顏色後按儲存,儲存時也會一併畫記。
2. **標籤**:在標籤欄輸入 `#保險科技 #ETF`(用空白、逗號分隔都可以)。全形的「＃」、英文大小寫(ETF 與 etf)都會自動視為同一個標籤,複習頁會把相同標籤的筆記統整在一起,點標籤就能只看同一主題。
3. **修改**:點已標記的文字,可以編輯註解、換顏色或刪除。
4. **整頁筆記**:點網頁右下角的 ✎ 圓形按鈕,開啟側邊欄,寫下整篇文章的心得。
5. **複習**:點工具列的「網頁筆記」圖示 → 「開啟複習頁」。可以搜尋、點標籤篩選、排序、直接修改註解,並回到原文。
6. **備份**:複習頁可匯出 Markdown(貼到 Notion、Obsidian 等),也能備份或匯入 JSON。

## PDF 文獻筆記

1. 點工具列「網頁筆記」圖示 → **📄 開啟 PDF 閱讀器**,把 PDF 拖進視窗(或按「開啟 PDF」選檔)。
   - 如果瀏覽器正開著一份網路上的 PDF,選單裡會多一個「📑 用網頁筆記開啟目前這份 PDF」,一鍵載入。
2. 選取文字 → **🖍 標記**(立刻畫起來)或 **💬 註解**(寫想法、標籤,儲存時一併畫記)。點已標記的文字可編輯或刪除。
3. 右側筆記欄有「文獻筆記」(整份文獻的心得)和標記清單,點清單可跳到那一頁。
4. 勾選「保存副本」時,PDF 檔會存在瀏覽器本機,之後從複習頁或閱讀器的「最近的文獻」就能直接重新開啟;不勾的話,之後重新開啟時需要再選一次檔案,筆記會自動接回去(用檔案內容比對,檔名改了也沒關係)。
5. 到**複習頁**,網頁和 PDF 都在同一份清單,可用「來源」篩選,也可切換「總覽(已讀清單)」一眼看到讀過哪些、各有幾則標記。每則 PDF 標記都有「第 N 頁 ↗」可直接跳回原文位置。

注意:
- 標記請在**同一頁內**選取,跨頁的段落請分兩次標記。
- 掃描版 PDF(整頁是圖片、沒有文字層)無法選取文字。
- PDF 副本佔用本機空間,可在複習頁的文獻卡片按「清除副本」(筆記保留)。備份 JSON 只包含筆記,不含 PDF 檔本身。
- 受登入保護的網站(例如需要校外連線的期刊),建議先把 PDF 下載到電腦再拖進來。

## 分享給別人

- **分享頁(HTML 檔)**:在網頁右下角 ✎ 側邊欄按「📤 下載分享頁」,或到複習頁勾選多篇文章後按「📤 分享所選」。會產生一個好看的獨立網頁檔,包含文章連結、你標記的段落、註解與整頁筆記。用 LINE、Email 傳給對方,對方直接雙擊開啟即可,不需要安裝任何東西,也可以用瀏覽器列印成 PDF。
- **分享連結**:在側邊欄按「🔗 複製分享連結」(複習頁每篇文章也有)。你的標記和筆記會被壓縮放在連結的 `#` 後面,不經過任何伺服器。對方需要先安裝「網頁筆記」擴充功能,用這個連結開啟原文,頁面上會跳出「匯入到我的筆記」,按下後標記和筆記就會出現(並加上「來自分享」標籤)。
- 連結太長(超過約 8000 字元)時,部分通訊軟體可能截斷,建議改傳分享頁。
- 分享內容包含你標記的原文段落,請留意原作者的版權,僅用於個人學習或合理引用。

## 注意事項

- 筆記只存在這一個瀏覽器。換電腦或重裝瀏覽器前,請先在複習頁「備份 JSON」。
- 清除瀏覽器資料或移除擴充功能,筆記可能一併消失,請定期備份。
- 如果網站改版,或內容是動態載入,舊的標記有時會找不到原文而不顯示;複習頁仍保留完整紀錄。
